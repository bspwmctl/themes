# bspwmctl themes

> 🚧 **Coming soon.** This repository is not open for submissions yet.

A community collection of themes for [bspwmctl](https://github.com/bspwmctl/bspwmctl).

## What will be here

Each theme will be a complete look for your bspwm desktop:

- 🖼️ Wallpaper
- 📊 Polybar layout and colors
- 🪟 bspwm colors, borders and gaps
- 🚀 Rofi launcher style
- 🖥️ Terminal (kitty) colors
- 🔔 Notification (dunst) style
- 📸 A preview screenshot

You will be able to apply any of them with a single command:

```bash
bspwmctl theme <name>
```

Your current configs are backed up before a theme is applied, so you can always go back with `bspwmctl restore`.

## Share your theme

Once the theme format is ready, you will be able to submit your own theme with a pull request. Every theme will be reviewed before being added.

Until then, you can follow the progress in the [bspwmctl repository](https://github.com/bspwmctl/bspwmctl) or [open an issue](https://github.com/bspwmctl/bspwmctl/issues) with your ideas.
